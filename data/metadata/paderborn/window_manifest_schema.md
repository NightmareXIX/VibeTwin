# Paderborn Window Manifest Schema

The full `data/metadata/paderborn/window_manifest.csv` is generated by `python scripts/preprocess_paderborn.py`. It is metadata-only but about 189 MB as a plain CSV, so it is not tracked in Git.

The tracked `window_manifest_sample.csv` contains the header and representative rows across healthy/fault splits, damage groups, and operating conditions. It does not contain raw signal values.

## Columns

| Column | Description |
| --- | --- |
| `split` | Dataset split: `train`, `val`, or `test`. |
| `subset` | Protocol subset, such as `train_healthy`, `val_healthy`, `test_healthy`, or `test_fault`. |
| `health_status` | `healthy` or `damaged`. |
| `damage_group` | Paderborn damage family, such as `KA`, `KB`, or `KI`; blank for healthy rows. |
| `fault_label_int` | Integer fault-family label for damaged windows; blank for healthy rows. |
| `fault_label_name` | Fault-family label name for damaged windows; blank for healthy rows. |
| `label_verification` | Label provenance used by preprocessing. |
| `label_support_files_present` | Whether local support documents were present for the bearing. |
| `bearing_code` | Paderborn bearing code, such as `K001`, `KA01`, `KB23`, or `KI01`. |
| `condition_code` | Operating condition code, such as `N09_M07_F10`. |
| `speed_code` | Parsed speed code. |
| `torque_code` | Parsed torque code. |
| `radial_force_code` | Parsed radial-force code. |
| `repeat_index` | Measurement repeat index parsed from the filename. |
| `filename` | Raw measurement filename. |
| `relative_path` | Repo-relative path to the raw measurement file. |
| `measurement_id` | Filename stem used as a measurement identifier. |
| `selected_signal` | Selected channel; this release uses `vibration_1`. |
| `available_channels` | Pipe-separated channel names available in the source file. |
| `signal_length` | Number of samples in the selected signal. |
| `window_index` | Window index within the selected signal/split region. |
| `window_start` | Start sample index of the window. |
| `window_end` | End sample index of the window. |

## Regeneration

python scripts/prepare_paderborn.py
