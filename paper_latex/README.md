# Manuscript Assets

This folder contains the manuscript source and the small figure/table assets needed to compile it from GitHub.

- `version_2.tex` is the main paper source.
- `figures/` contains the promoted figure files referenced by the paper source.
- `tables/` contains the LaTeX tables referenced by the paper source.
- `diagrams/` contains methodology diagrams.
- `VibeTwin Conference v1.pdf` is a compiled PDF snapshot.

The larger paper-package export under `artifacts/` is intentionally not tracked because it is generated output.
